# 任务：优化一个 PoE2 攻略网站的信息架构与移动端体验

## 一、要优化的东西

**网站**：https://harryghost.github.io/poe2-guide/
**技术形态**：**单个静态 `index.html`**（约 125,000 字符），没有框架、没有构建工具。
页面用纯 JS 做「点导航切换 section 显示」，深色主题，全部中文。
仓库：https://github.com/HarryGhost/poe2-guide

内容是关于国服《流放之路：降临》0.5.5 一个职业（锐眼冰射）的新手攻略，
从 1 级到后期的完整流程，包含下载 `.build` 文件、天赋树截图、装备表、对照表等。

## 二、用户的痛点（真实反馈，别忽略）

1. **「太乱了」** —— 导航栏现在有 17 个按钮，一屏放不下；新手进来不知道从哪看
2. **「太长的页面」** —— 有几页非常长（装备页约 38,000 字符），要滚很久
3. **手机上看** —— 大量表格、图片网格，窄屏下显示不好
4. **图片是 1500px 宽**，有几张接近 400KB，加载偏慢
5. 用户是**纯新手**：他要的是「我现在该干什么」，不是资料库式列举

## 三、现在的结构（17 页）

导航顺序：

```
[阶段页 · 按他的攻略进程分]
1️⃣ 1–14级   2️⃣ 造弓   3️⃣ 转冰   4️⃣ 第四章   5️⃣ 异界   6️⃣ 暴击   7️⃣ 成型
[参考页]
⚔ 技能全表   🎯 输出手法   🌌 异界后（成型）   🔨 装备全流程
🧭 加点与属性   📖 对照速查   🎬 视频笔记   🖼 配图总览
🤖 给GPT的指令   🔗 他的链接
```

每个阶段页里固定四块：①这一阶段要做什么（清单）②技能怎么搭 ③天赋怎么点 ④装备什么时候换。

## 四、请你做四件事

### 1. 信息架构：给出一个更好的导航方案
现在 17 个按钮太多。请提出一个**两级或分流式**的方案，例如：
- 顶部只留 4~6 个主入口（阶段流程 / 参考 / 资料 / 下载）
- 阶段之间用「上一阶段 / 下一阶段」翻页，而不是全靠顶部导航
- 或者一个「我现在多少级？」的分流入口

**要求**：给出改法的具体形式（导航项名称 + 层级），不要泛泛说「建议简化」。

### 2. 移动端适配：直接给 CSS 补丁
请看现在的样式表（从页面源码里能看到，都在一个 `<style>` 块里），指出问题并给出**可直接粘贴的 CSS**，重点是：
- 顶部导航在窄屏下横向溢出 → 怎么处理（横向滚动？折叠成汉堡菜单？）
- 宽表格在手机上挤压 → 怎么处理（横向滚动容器？卡片化？）
- 图片网格（`.gal` / `.figgrid` / `.treegal`）在窄屏下的列数
- 正文行高、字号、间距在手机上的可读性

### 3. 加载性能：给出具体做法
- 图片现在 1500px 宽、最大约 400KB、共 60+ 张。给出压缩/响应式方案（不需要构建工具，因为网站是手写 HTML）
- `loading="lazy"` 已经加了，还有哪些能立刻做的（尺寸属性、`decoding="async"`、首屏图片优先级等）

### 4. 内容去重：列出该合并/删除的部分
页面之间可能有重复的板块（比如「升华顺序」在速查页和天赋页都出现过）。
请指出**哪些板块重复、建议保留哪一处**。

## 五、硬性约束（很重要）

1. **不要改攻略内容的文字** —— 那些是照抄原作者（B站UP主「网瘾老年人lowK」）的文档和视频，改错了就是误导新手。你可以改**排版、结构、导航、样式**，不要改文字里的数值、名称、步骤。
2. **不能引入构建工具** —— 目标是「一个 index.html + 图片文件夹」，改完要能直接扔到 GitHub Pages 上跑。
3. **不要引入外部 CDN** —— 现在整个站点零外部依赖（只有图片是本地的），请保持。
4. **深色主题保持** —— 现在的配色变量：`--bg:#0d1117 --panel:#161b22 --panel2:#1c2330 --line:#2b3542 --tx:#e6edf3 --tx2:#9aa7b4 --gold:#d4a24c --cyan:#4ec9d0 --red:#e05252 --green:#4caf7d`
5. **中文排版** —— 注意中文字体和西文混排的行高（现在正文 `line-height` 偏紧）。
