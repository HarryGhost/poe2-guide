先记住三件事（这三件做错，其它都白搭）

① 冰冻印记必须放在武器组 2。所有输出技能放武器组 1，只有冰冻印记放武器组 2。它的增益持续 20 秒，全程保持。
② 冰霜射击 31 级才解锁。1–30 级用闪电箭矢 + 引雷针，31 级才能换冰霜射击 + 寒冰之捷。
③ 别用元素军械 III，只用元素军械 II（III 那版的收益和代价不成正比）。

路线 · 从头到尾 6 个阶段

每一阶段只回答三件事：什么时候开始、现在做什么、装备怎么选 / 别做什么。等级只是参考，按你自己的进度看。

1早期 · 第一章等级参考 1–14 级

什么时候开始：创完角色、拿到第一个技能宝石就能开始。这一段重点不是伤害，是别乱花通货。

现在做什么
技能：闪电箭矢（清图主力）+ 引雷针（打首领）。
辅助宝石顺序：快速攻击 I → 元素军械 I → 范围集中 → 第二个元素军械 I。
早期首领顺序：吞噬者（泥沼）→ 冰巫婆（清沼）→ 小屋巫婆（灰林）→ 锈王（红谷）。熟练了可以跳过吞噬者。
等级纪律：在红谷拿短弓，练到 5 级再去打锈王。
商店：每 1–2 级回城看一次，找加点伤的手套和带移动速度的鞋。第一章点伤极其关键。
装备怎么选
弓：11 级拿守望者弓，挑 DPS 最高的一把，一点资源都别投。
箭袋：+等级 + 高额点伤。
药剂：生命 / 魔力药剂全程跟着等级换（10/16/23/30/40/50/60 级有新一档）。
其它：优先闪避或闪避/Es 混合装，但哪件好看用哪件。
别做这些：不要用通货去做 11 级那把守望者弓 —— 它只是过渡。把工匠石、崇高石、富豪石全部留到 16 级做反曲弓（6 条词缀、2 个插槽）。
前期没辅助宝石时，元素军械 I 要在闪电箭矢和引雷针之间手动换（打首领换给引雷针），力量不够同时撑两个。
2中期 · 做第一把真弓等级参考 15–23 级

什么时候开始：练到 16 级、把反曲弓做出来。这把弓会陪你到进异界。

现在做什么
做弓（最重要的一件事）：16 级，反曲弓打满 6 条词缀、2 个插槽。
技能：还是闪电箭矢 + 引雷针，寒霜爆继续带着。
辅助：把第二个元素军械 I 补上（引雷针也吃满）。
商店：继续每 1–2 级看手套和鞋。
装备怎么选
弓：反曲弓，目标词缀 = 物理伤害 % + 点伤 + 攻速/暴击。做不出来就用掉落里 DPS 最高的。
弓的符文：后期用高级钢铁符文（最高 DPS）；两个插槽先用剧情符文。
防具：生命 / 抗性优先，闪避次之。
别做这些：24 级会做一次小换技能，所以6 级和 7 级的未切割宝石在这一段一个都别用，留着。
3过渡 · 为换冰做准备等级参考 24–30 级

什么时候开始：24 级做一次小换技能，把技能位和辅助宝石提前配到位，这样 31 级能一次换干净。

现在做什么
换技能：按 24 级的配置调整（保留闪电箭矢 + 引雷针作为主输出，补齐需要的辅助）。
攒宝石：把 6/7 级未切割宝石留着，31 级要用一大把。
商店：开始留意+等级箭袋和点伤手套，这两件在 31 级之后收益仍然最大。
装备怎么选
抗性：每章结束抗性会被扣（−30% / −60% / −70%），记得补火冰电。
鞋：移动速度是这一整套装备里性价比最高的词条，见到就换。
别做这些：不要提前学冰霜射击（31 级解锁），也不要提前开寒冰之捷（30 精魂）。
4定型 · 换冰霜射击等级参考 31–41 级

什么时候开始：31 级解锁冰霜射击。这是整个 build 唯一一次「换流派」的节点，之后就定型了。

现在做什么
一次换干净：冰霜射击（主输出）+ 寒冰之捷（清图光环）+ 狙击（打首领）+ 龙卷射击 + 冰尖箭矢 + 弹幕 + 冰冻印记。
武器组：输出技能全放武器组 1，冰冻印记放武器组 2，全程保持它 20 秒的增益。
首个 4 孔：给冰霜射击。
辅助：看「技能」页的完整表。
装备怎么选
箭袋：+投射物等级 + 点伤/弓伤 + 攻速，凑 3–4 条就很好。
手套 / 戒指：高额点伤（优先冰霜或物理）。
衣服：高闪避，防御最吃这一件。
别做这些：如果你用弹幕 + 战斗狂怒的连招，就不要点共鸣：共鸣会把「获得的狂怒球」改成暴击球，弹幕没球吃，爆发就没了（这条有玩家专门问过，Fubgun 的回答就是不要）。不用弹幕的话无所谓。
5推进 · 补强度等级参考 42–59 级

什么时候开始：技能换完之后，这一段全部重点是「把伤害和抗性推上去，别停」。

现在做什么
继续点天赋（主线 106 → 123 点，武器组各 20 点）。
抗性：火冰电 75%，混沌 30–50% 即可。
稀有度：有余力堆到 100%，刷图收益明显。
宝石：攻击伤害、元素伤害、投射物伤害、攻速、暴击率/暴击伤害、箭袋加成、移速。
蓝耗：会开始缺蓝 —— 拿一颗蓝宝石宝石带击杀回魔，或等泉井之心。
装备怎么选
项链：至少 30 精魂才能开满精神宝石；+投射物等级最好。
腰带：生命 / 力量 / 抗性，力量交给腰带解决。
别做这些：缺蓝的时候不要硬堆智力或魔力上限，先解决「击杀回魔」。
6进异界 · 转暴击等级参考 60 级以上

什么时候开始：进异界之后（大约 60–65 级）开始按下面的顺序换装。这一段最花钱，按顺序来别乱。

现在做什么
换装顺序（Fubgun 的原文顺序，照做）：
1. 先把非暴击那一套配完整，加一颗泉井之心（便宜、提升大，配 3 词条宝石）。
2. 再去搞一把好暴击弓 + 好暴击箭袋，拿到了才转暴击（或者用卡迪罗的赌局过渡）。
3. 一件大闪避衣服对生存是质变。
4. 转混合（Hybrid）的时候，目标是 450 左右 Es 的头盔。
5. 之后补鞋 / 手套 / 戒指 / 项链（项链 +投射物等级 / 精魂）。
6. 最后拿抗衡黑暗，要「作为额外冰霜伤害」那条，后期追双额外。
低优先级（太贵、性价比不够，有钱再说）：拉其塔之流 / 格鲁坎的决心 / 仪式通道 / 猎首。真要买先买猎首。
装备怎么选
头盔：转混合时换成纯 Es 头盔 + 天赋诡计面纱。
衣服：高闪避 + 猛兽之肤天赋，配高级钢铁符文。
项链：+投射物等级 + 至少 30 精魂，后期追 50 精魂。
别做这些：别在弓还不行的时候去堆稀有度或防御 —— 先把弓和箭袋搞定。
一句话版：整个流程的时间轴

装备 · 每个部位看什么

先看「硬性要求」，再看各部位。下面 6 个折叠块对应 Fubgun 原文里的 6 个阶段，需要时展开。

硬性要求（不满足就先别往下打）

项目目标
火 / 冰 / 电 抗性75%（三个都要）
混沌抗性30–50% 就够，不强求 75%
属性大概率需要在装备上找 1–2 条属性：力量交给腰带，缺智力就在戒指或项链上找

各部位优先级

部位核心词条说明
戒指 / 手套高额点伤（优先冰霜或物理）第 1、2 章点伤的收益最大，商店每 1–2 级看一次
弓能拿到的最高 DPS首选底子毁灭者之弓（基础伤害高，缺点可忽略）；没到之前用掉落或买得到的最高 DPS 弓。符文用高级钢铁符文
箭袋点伤 / 弓技能伤害 + 投射物速度 + 攻速凑到 3–4 条就是好箭袋；卡迪罗的赌局是暴击前的过渡选择
项链+投射物技能等级 + 精魂转暴击之后暴击率 / 暴击伤害也好；属性、抗性都可以放这里
头盔前期：生命 / 闪避 / 抗性转混合时换纯 Es 头盔 + 天赋诡计面纱（目标 450 Es）

腰带生命 / 力量 / 抗性没多少选择；后期换猎首
天赋树宝石通用伤害：攻击伤害 / 元素伤害 / 投射物伤害 / 攻速 / 暴击 / 箭袋加成 / 移速后期追泉井之心（双「额外」）和抗衡黑暗（额外冰霜，最后追双额外）

三件「机制件」，别漏

① 一颗带「击杀回魔」的蓝宝石宝石。刷图时蓝耗全靠它，否则会一直站着回蓝。
② 打首领的蓝耗：冰冻印记插上 虹吸印记 II + 永恒印记，回魔就够了 —— 这是 Fubgun 专门指出的组合。
③ 头盔涂油（Anoint）= Zarokh's Gift：给树上多一个宝石插槽，会显示在你的升华旁边（他毕业配置里就是这么做的）。

Fubgun 原文的 6 个阶段装备（折叠）

① Early（初进地图 / 进异界前后）

这是本 build 的起点，也是唯一一套你不需要花钱就能凑齐的配置。Fubgun 原话：这套用纯独狼（SSF）也拿得到。

部位要什么
整套方向非暴击 + 纯生命 / 闪避。
② non-crit Midgame（非暴击中后期）
项目做法
换装重点继续非暴击，把点伤、弓 DPS、闪避、生命往上推。
宝石开始补宝石（攻击 / 元素 / 投射物伤害），或者先上泉井之心。
提醒这一阶段不要急着转暴击 —— 暴击弓和暴击箭袋不到位，转了反而更弱。
③ non-crit Hybrid swap（非暴击 + 混合防御）
项目做法
防御换成混合（Es）防御：头盔换纯 Es（目标 450 Es）+ 天赋诡计面纱。
输出还是非暴击，靠点伤和宝石堆。
提醒混合之后能量护盾是主要缓冲，注意被连续打中时 Es 充能会停。
④ Crit Hybrid（暴击 + 混合防御）
项目做法
武器暴击弓 + 暴击箭袋是关键；没有就用卡迪罗的赌局过渡。
天赋补暴击率 / 暴击伤害节点。
效果冰霜射击更容易冻住首领，首领流程会顺很多。
⑤ Uber Endgame（毕业）
项目做法
追求弓做到最好（见「打造」页）、箭袋 5 条、项链 +投射物等级 + 50 精魂。
宝石泉井之心双额外 + 抗衡黑暗双额外。
可以丢掉的装备够好之后可以不要狙击，变成单键 build。
低优先级拉其塔之流 / 格鲁坎的决心 / 仪式通道 / 猎首 —— 有钱再买，先买猎首。
⑥ Live Gear（作者本人当前配置）
项目说明
这是什么Fubgun 页面上还有一个「他当前角色」的配置，是他账号的毕业状态，偏后期。
怎么用先按 ①→⑤ 走；等你也毕业了再去看那个 tab。对中期没有参考价值。

技能 · 宝石 / 武器组 / 连招

① 武器组怎么分（最重要）

输出技能全放武器组 1：冰霜射击 · 狙击 · 龙卷射击 · 冰尖箭矢 · 弹幕 · 寒冰之捷
冰冻印记放武器组 2：它不属于输出，靠武器组切换常驻。它给你的增益持续 20 秒，全程别让它断。

武器组技能 = 天赋树上的「武器组天赋点」只在这组武器激活时生效；技能面板里每个技能右上角可以指定属于武器组 1 还是 2。没带第二把武器也能设：把第二武器位留空，右键武器上方那个 “I” 图标，让它同时属于两组。

④ 打首领的按键顺序

目标是把首领冻住，然后接弹幕 + 狙击。

1. 先在场上放一个龙卷射击（提前放，不是开打了才放）
2. 挂上冰尖箭矢
3. 一直按冰霜射击，直到首领被冻住
4. 确认场上还有龙卷射击 → 按弹幕 → 按狙击
5. 重复。狙击炸开的那一下就是全部伤害。

平时刷图：只按冰霜射击。狙击只留给地图首领 / 大怪。

⑤ 两个必须说的机制坑

① 用弹幕就别点共鸣（Resonance）。共鸣的效果是：获得的狂怒球改成暴击球、耐力球改成狂怒球、暴击球改成耐力球。弹幕要吃狂怒球，点上它弹幕就没球可吃。如果你用战斗狂怒 + 弹幕的爆发循环，这条必须避开；不用弹幕的配置则不受影响。

打造 · 弓 / 箭袋 / 项链 / 头盔

打造部分是英文原名较多的区域：很多通货在国服有官方译名，但网上查不到统一译法，所以下面写成 中文名（+英文原名），两边都能对得上；完整对照见 术语对照.md。

通用前提：底材等级 ilvl 75（项链 80/82）。先 aug（增幅）打满再动稀有通货。这一版的打造被砍过，所以做一把能用的弓很现实，做极品弓还是靠运气。
① 弓 — 非暴击版（早期就该做）

前提：一把高物理伤害 % 的弓（多少都行，越高越好）。可以自己掉、也可以买底材，用 trans/aug 洗到高 %物理。

  1. 拿到高 %物理 的弓（先 aug 打满），用 强效磨蚀精华（Greater Essence of Abrasion）→ 给 T3 附加物理伤害。
  2. 用 左旋死灵预兆（Omen of Sinistral Necromancy）+ 遗存颚骨（Preserved Jawbone）揭示（unveil）一条前缀。看价格也可以用 深渊回响预兆。目标：揭出高额的附加元素伤害（冰霜最好）。
  3. 剩下就是随机：按你的弓有多好和通货价格，用 崇高石 / 完美崇高石（Greater / Perfect Exalted Orb）+ 强效崇高预兆（Omen of Greater Exaltation）把最后两条词缀填满。

最好的底子：毁灭者之弓 或 寻战之弓。

② 弓 — 暴击版（转暴击时做）

步骤和非暴击版几乎一样，只换第一步的精华。

  1. 高 %物理 的弓 + aug 打满 → 寻觅精华（Essence of Seeking）→ T3 暴击。
  2. 左旋死灵预兆 + 遗存颚骨 揭示前缀（早期穷可以用便宜的颚骨）。目标是高额附加物理，高 Tier 的元素附加也可以接受。
  3. 用 Greater / Perfect Exalted Orb + Omen of Greater Exaltation 补最后两条词缀。
③ 箭袋 — 便宜做法（推荐）
  1. 用完美点金/增幅（Perfect trans/aug）洗到两条好词缀（前缀：点伤 或 弓伤害 %；后缀：+1 等级 / 暴击 / 攻速）。
  2. 完美富豪石（Perfect Regal），期望第 3 条也是好词缀（出在后缀最理想）。
  3. 如果出了坏词缀，可以用强效混沌石尝试替换 —— 这里 2/3 概率直接报废，谨慎。
  4. 上 右旋死灵预兆 + 遗存颚骨；如果已经是 3 条极品词缀，用 深渊回响预兆。
  5. 如果后缀很理想，考虑 完美崇高石 + 双崇高预兆收尾。

这是做「极品箭袋」最便宜的路子，随机步骤多，但迟早能中。更贵的方法要用 光明预兆（Omen of Light）、破溃宝珠（锁词 fracture）和 whittles。

④ 箭袋 — 贵价做法（已有好底子时）
  • 如果后缀出了 +2 等级 / 暴击、前缀有 T1 点伤：给后缀上遗存颚骨，然后赌 1/3 破溃宝珠（锁词） —— 没锁中也没关系，回到便宜做法继续。
  • 如果锁住了点伤：前缀用崇高石加 1 条，然后 浮夸精华（Essence of Hysteria）+ 左旋结晶精华，可以 100% 给前缀加弓伤害。最后一条前缀用 完美崇高石 砸，祈求别出命中。
  • 如果箭袋已经有 5 条极品词缀：用深渊回响预兆 / 光明预兆 反复洗最后一条后缀，直到出暴击或攻速。
⑤ 项链 — 确定性做法（贵，但可预期）

ilvl 80 或 82（82 出 T1 抗性）。基本是确定性的流程，只需要一个锁词底子。

  1. 用破溃宝珠锁词，或直接买一条 +3 投射物等级 的项链。
  2. 剥离到只剩 2 条词缀（锁词 + 1 条随机）。
  3. 用混沌石洗到 T1/T2 精魂。
  4. 用 右旋崇高预兆（Omen of Dextral Exaltation）+ 一次崇高石，补 1 条后缀。
  5. 上 右旋结晶预兆（Omen of Dextral Crystallisation）+ 强化精华（Essence of Enhancement）。
  6. 用你要的元素催化剂（Tul / Xoph / Esh）把项链品质做到 20%。
  7. 完美崇高石 + 右旋崇高预兆 + 催化崇高预兆（Omen of Catalysing Exaltation）—— 高概率出抗性。
  8. 如果出了抗性，重复第 7 步（催化剂可以继续用，因为项链还能吃到全抗）。
  9. 如果出的是暴击 / 稀有度这类好属性也可以留；不是就走「剥离石 / collarbone + 右旋死灵预兆 + 光明预兆」把这条去掉重来。
  10. 最后：collarbone + 深渊回响预兆 + 光明预兆，直到洗出你要的最后一条前缀。
⑥ 头盔 — 两种做法（做 450 Es 那件）

便宜做法（ilvl 78）

  1. 买或完美点金/增幅底材，洗到 T1 能量护盾。
  2. 上 强效强化精华（Greater Essence of Enhancement）。
  3. 上 左旋死灵预兆 + 遗存肋骨（Preserved Rib）。
  4. 揭示，拿任意 复合 %Es。
  5. 如果复合 %Es 是 T1：完美崇高石 + 强效崇高预兆；否则用普通强效崇高收尾。

便宜但更随机（有博到三 T1 前缀的机会）

  1. 买或完美点金/增幅底材，洗到 T1 %Es 或 T1 +Es。
  2. 如果前/后缀好（好后缀 = 抗性 / 暴击 / 稀有度），用抗性或稀有度精华。
  3. 左旋死灵预兆 + 遗存肋骨，然后 强效崇高石 + 强效崇高预兆。
  4. 如果出了好的复合前缀 Tier（T3/T2/T1），用 深渊回响预兆 赌更好的 Tier。
  5. 前缀 Tier 高的话，最后用 腐化宝珠（Vaal Infuser） 收尾（有概率腐化，但物品不会报废；用之前先打孔）。
⑦ 绿宝石（翡翠珠宝）— 贵，做完上面再说
  1. 买或锁 攻击暴击伤害加成（要 20%）。
  2. 混沌石洗出 暴击率提高。
  3. 确保是 4 词缀宝石，然后用 强效的液化轻蔑（Potent Liquid Contempt）；如果暴击后缀被洗掉，回到第 2 步。
  4. 用 遗存头骨（Preserved Cranium）+ 深渊回响预兆 + 光明预兆 反复洗，直到揭示出 攻速。
  5. 拿到想要的后缀后，用 左旋剥离预兆 剥离前缀（如果没剥中 +1 后缀，得做两次）。
  6. +1 后缀工艺词缀被去掉后，用崇高砸到 5 条词缀。
  7. 混沌石洗出 1 条好前缀（投射物伤害 / 元素伤害 / 对稀有怪伤害 / 攻击伤害）。
  8. 最后用 强效的液化凶残（Potent Liquid of Ferocity），50/50 收尾；如果好词缀被洗掉，回到第 7 步。

要诀 · 机制与坑

① 为什么这套是「冻住再打」—— 冻结机制
  • 冰霜射击的伤害本身不夸张，真正爆炸的是狙击；狙击要的是稳定命中同一个目标。
  • 首领被冻住时不会移动，所以「冻住 → 弹幕（吃狂怒球）→ 狙击」是这套的核心爆发。
  • 冰冻印记（放武器组 2）是让你更快冻住，不是加伤害的增益，所以别指望它把数字拉高。
  • Fubgun 的实战建议：提前放龙卷射击，然后在冻住前一直按冰霜射击，别停下来。
② 蓝耗：三个来源就够
  • 击杀回魔：天赋树上一颗蓝宝石宝石带「击杀获得魔力」就够刷图了。
  • 泉井之心（宝钻）：本身也带击杀回魔，是早期最便宜的提升。
  • 打首领：冰冻印记上 虹吸印记 II + 永恒印记 —— Fubgun 专门点出的组合。
  • 参考：有玩家用「审慎施法 + 拉维昂加 + 魔力残片」三件套解决缺蓝。
③ 幻影射手 / 风舞者 怎么选
  • 标准配置是幻影射手（自动帮你打，清图更顺）。
  • 精魂不够就把它换成风舞者，插 致盲 II + 击退 —— 生存更好，输出略降。
  • 想把「寒冰之捷 + 风舞者 + 战斗狂怒 + 幻影射手」全开：项链 +30 精魂起，间章再做多瑞亚尼任务线拿 +40 精魂，再配一个带额外技能栏位的戒指（它不占技能栏）。
④ 「Live Gear」那一页要不要照抄
  • Mobalytics 上还有个 Live Gear tab，那是 Fubgun 自己账号的当前状态（接近毕业，还带大量宝石）。
  • 有玩家问过「什么时候能切到 Live Gear」，社区的回答是：那是后期才碰的东西 —— 需要大量宝石和一把附加箭数很高的弓。
  • 你现在该做的是 ①→⑤ 的阶梯，不要跳。
⑤ 早期最容易被误杀的三个「省事想法」
① 「抗性满了，先堆稀有度」 —— 伤害/生存不足时先别管稀有度（Fubgun 原文也是这个意思）。
② 「元素军械 III 更强」 —— 不要用 III，只用 II。
③ 「先买贵的传奇」 —— 拉其塔之流 / 格鲁坎的决心 / 仪式通道 / 猎首 是低优先级，先买猎首，或者干脆先买弓。

常见问题

我现在这个等级应该看哪一页？
  • 1–30 级 → 「路线」的阶段 1–3（技能还是闪电箭矢 + 引雷针）
  • 31–59 级 → 阶段 4–5（刚换成冰霜射击）
  • 60 级以上、在异界 → 阶段 6 + 「装备」页的换装顺序
非暴击 / 暴击 / 混合，到底要选哪个？
  • 它们不是三种流派，是同一套 build 的三个阶段。
  • 顺序永远是：先非暴击配齐 → 弓和箭袋变好 → 转暴击 → 用混合（Es）防御。
  • 跳阶段会变弱：暴击弓不到位就转暴击，伤害反而下降。
没有第二把武器，怎么把冰冻印记放武器组 2？
  • 把第二武器位留空，右键武器上方那个 “I” 图标，它会同时属于武器组 1 和 2。
  • 然后在技能面板里把冰冻印记指定为武器组 2 即可。
为什么我的冰冻印记放进武器组 2 就消失了？
  • 最常见原因是武器组 2 上装了武器，导致「一组技能只在对应武器组生效」的规则把它挡掉了。
  • 把第二武器位留空（见上一条）就能正常使用。
为什么我的技能显示成粉色 / 绿色？
  • 粉色表示该技能被指定给武器组 1，绿色表示武器组 2。
  • 这不是报错，是武器组分配的视觉标记。
冰霜射击要几个宝石？「三个冰霜射击」是什么玩法？
  • 幻影射手需要自己的一份冰霜射击宝石来打，所以常见做法是：主用的那份做品质 / 六连，另外两份用普通切出来的宝石给幻影。
  • 总共 3 份冰霜射击：1 份你自己用（升级 / 打孔 / 品质），2 份给幻影。
我没有 6 连，技能怎么插？
  • 按优先级从后往前删辅助：狙击 → 冰霜射击 → 寒冰之捷 → 冰冻印记。
  • 也就是说缺孔时先保证狙击的连接质量，再考虑其它。
这套能不能纯独狼（不交易）玩？
  • Fubgun 的原话：早期那套装备用纯 SSF 也拿得到，或只需极少量交易。
  • 真正难的是后期那把「好暴击弓」和好箭袋 —— 这两个位置在独狼里主要靠自研打造（见「打造」页）。
  • 装备方向：点伤靠商店 / 掉落，弓靠底材自研，符文靠掉落的高级钢铁符文。
抗性要多少？为什么我一直被秒？
  • 火 / 冰 / 电 75%（三个都要），混沌抗 30–50% 就行。注意剧情每章结束会扣 −30% / −60% / −70%，很多人是忘了补。
  • 被秒的另一个原因通常是闪避 / 偏斜不够，或者没穿大闪避衣服。防御的第一优先级是衣服的闪避值。
狙击什么时候可以丢掉？
  • 装备足够好之后。Fubgun 的说法是：装备到一定程度可以不要狙击，变成只按一个键的刷图 + 打首领 build。
  • 在那之前，别丢。
这个网站和 Fubgun 英文原文的关系？
  • 本页是 Mobalytics 的 Fubgun 冰射锐眼（0.5.5） 的中文整理版，加上国服术语与一位国服实况角色的参考数据。
  • 练级篇原文：Ice Shot Deadeye Leveling Guide。
  • 英文原文全文也存了一份在下载区，方便对照。
