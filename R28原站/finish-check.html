宝石：升级、开辅助孔、加品质是三件事

想做什么直接操作顺序完成后检查
升级已有主动技能取得足够等级的未切割技能宝石 → 打开刻印界面 → 选择已有的目标技能升级 → 先读新等级需求与消耗，再确认。技能有效等级、技能基础等级与“＋投射物等级”分开；升高后不一定仍能供蓝。需求不满足可先保留材料。
增加辅助槽在技能宝石上使用对应工匠石：低等设为3辅助槽、高等设为4、完美设为5；按客户端前置与宝石等级要求。1主动＋5辅助俗称六连。不要点到弓上；装备符文孔使用巧匠石。
补辅助连接先按该阶段已有连接从前往后补；缺一孔从末端取舍。元技能内部主动和辅助逐个确认。同一技能不能装同类别冲突辅助；部分传奇辅助全套不能重复。同名普通辅助的旧版全套唯一限制不要生搬。
技能品质确认是值得长期用的那颗技能 → 右键宝石匠的棱镜 → 左键目标技能一次 → 读取品质说明与变化。并非所有技能品质都加伤害；不去强化此阶段根本没有的狙击。
暂时不够材料保留能用的低阶辅助和现有连接；先解决武器／属性／供蓝的硬缺口。“已用作者技能名”不代表已满足高阶辅助的触发条件。

Ⅰ/Ⅱ/Ⅲ辅助也不一定只是数值更高：某些高阶限制会禁止造成元素异常。负责冻结的冰射不能盲目替换。

药剂、咒符与没有小怪时的恢复

项目你直接检查什么常见误解
生命药剂装备在药剂栏、读实际按键；看整次回复量／耗时、每次耗充能、是否有即时回复。回到安全处用充能恢复来源补满。“瞬回一部分”与“总回复提高”不同；不因为稀有度或底子等级高就默认更好。
魔力药剂连续释放当前主技能与完整首领链，记录是否先断蓝；再比较药剂回复、消耗与充能。击杀回蓝和击杀充能不能代表无小怪首领续航；物理偷取也不是总元素伤害偷取。
咒符装备在已开放的咒符栏；看触发异常、剩余充能与持续时间。达到条件后自动触发，不需要照药剂方式按键。有咒符不等于永久免疫；相同异常不要误认为多放就无限常驻。最多3槽，已开放数看角色。
品质玻璃弹珠用于药剂品质；已有品质咒符的品质提高持续时间。本次未确认国服主动加咒符品质用法，不把药剂材料直接列成咒符必做步骤。
特殊药剂／咒符按当前分支原件的完整效果和代价看；没有暗金先保留可靠的普通／魔法替代。替代后失去的护盾回复、猛攻等收益，不继续计入面板预期。

项链涂膏与首饰催化：可选收尾，不是符文

作者的可选涂膏：锯齿锋缘 / Serrated Edges

液化偏执 ×1 ＋ 液化憎恶 ×1 ＋ 稀释的液化贪婪 ×1。

打开液化情感的灌注／涂膏界面，将项链与三份材料放入 → 先看预览是否为“锯齿锋缘” → 无误再确认 → 检查项链已获得该节点。未出现预览或等阶不符就退出，不照颜色猜。

当前效果：攻击暴击率提高10%；对稀有／传奇敌人的攻击伤害提高30%。两者不是“+10%基础暴击”和“30%更多伤害”。作者说后续转暴击时收益更合适，不是Early强制。

催化操作判断
先在戒指／项链上找到真正要提高的属性，再选对应该类的催化剂。没有那种属性，催化不会生成；更换催化类型不把不同品质全部叠加。
先用一次，读取品质类型、数值及对应属性是否改变；再按预算继续。固定值、等级词缀、特殊词缀是否可强化不能一概而论，以预览与标签为准。
高级项链工艺中的催化崇高／返工，回原工艺逐轮执行。材料可能消耗品质；普通收尾和工艺中间投入不是同一件事。

不是每件装备最后都要神圣、腐化或符文锻造

操作为什么不列为新手必做
神圣石重新掷属性数值，不是只涨不跌，也不保证提升词缀阶级。先读物品状态与预算。
瓦尔宝珠、建筑师宝珠、特殊注能存在随机修改、腐化或摧毁风险；不是普通品质做满后的固定下一步。唯一主力装先不要试。
萃取石摧毁装备才能返还非插槽绑定增幅器。与覆盖一个普通符文完全不同。
符文锻造改变底材防御结构，与给孔装符文不同；可能降低你依赖的闪避／护盾。
刷六条满词缀4条或5条已合用也可停。6条表示容量，不代表6条都有用，更不代表毕业。

回城整理与开图：每轮只选一个目标

回城：鉴定准备使用的候选 → 能改善现在的先比较；40～50多ilvl普通过渡能用就用，不为毕业大量囤白底 → 无自用计划且可回收的按预览处理 → 把预算留给下一件确实能改善的装备。

进图：先读地图词缀，看它是否削弱当前防御、回复、命中或冻结；当前难度不稳定就选更稳的图，不把途石加满词缀当固定操作。新增额外难度后先小范围试，不把一次失败就归结为整套BD错了。
