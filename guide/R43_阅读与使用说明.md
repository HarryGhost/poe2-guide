# R43｜阅读与使用说明

日期：2026-10-05。以本次上传的 Codex 采集包核对 R42 后生成。

## 打开

将完整网站包解压到一个新目录，打开 `index.html`。不需要运行脚本、安装依赖或构建网站。开启浏览器 JavaScript，保持解压目录中的相对路径；不要混用旧版首页与新版 assets。

## 当前 build 的装备在一页内看全

页首直接按原名称选择：

`Early` → `non-crit Midgame` → `non-crit Hybrid swap` → `Crit Hybrid` → `Uber Endgame`

`Live Gear` 独立只读，不作为必经第六阶段。上述顺序是阅读次序，不是固定等级或强制转型顺序。

装备页默认展开十件主装备、两瓶药剂、三枚咒符、实际有记录的第二武器组，以及当前 build 的全部可见人物珠宝。可以向下滚动，不必逐个点开才能读属性；桌面两列、手机一列。

括号数字是原页面板范围，不是作者的确定掷值。顶部伤害／防御来自面板，不能再把下方词缀或符文重复叠加。品质未打印就显示未写，原保存值可在证据中展开。没有配置物品与“工具未取得属性”分别标注。

每件下方的“英文原面板、保存描述与证据”可查原文和实际截图。部分页面存在保存字段与悬浮框冲突，黄色提示不等于我选择其中一方作为真值。

## 其他内容分开阅读

- **人物配置：**默认技能连接、内嵌主动、武器组，以及人物天赋截图、参考树等级、切换条件。人物珠宝与技能／辅助宝石不混在一起。
- **异界攻略：**七套方案分别查看原图、作者大节点已选项、大师配置、地图碑牌和操作。这里的作者已选项来自本次采集绑定；旧备料建议另标为建议。
- **装备打造：**从某件装备进入时保留 build 与部位；先选择普通过渡或作者专用路线，再按手中状态看当步材料、动作、验收和停手。原页示例并非每一步保证能做出的结果。
- **剧情与资料：**保留 R42 的剧情阶段路线、永久奖励、升华、卡关排查及原版过滤器。新增核对记录可直接查源证据。

从装备卡进入打造或人物配置，再回到装备总览，仍保留当前 build。搜索支持新取得的珠宝、镶嵌物名称、节点及已选效果。

## 过滤器

只使用“剧情与资料 → 四份原版过滤器”或 `原版过滤器_从这里选` 目录中的文件。四份都是此前保存的原文件，没有调整颜色、声音、底材、碎片、金币或其他规则。

旧 `filters` 目录仍保留历史副本，仅用于追溯；GoldFix、Materials、Bases_Shards 等文件不是原版。更新网站也不会自动改变游戏当前启用的过滤器。
