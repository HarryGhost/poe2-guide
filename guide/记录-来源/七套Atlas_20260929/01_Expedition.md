# Expedition

来源：[Fubgun — Fubgun Atlas Tree and Strats for 0.5](https://mobalytics.gg/poe-2/atlas-trees/fubgun-atlas-tree-strats)；[攻略首页](https://mobalytics.gg/poe-2/atlas-trees/fubgun-atlas-tree-strats)。

页面显示更新：2026-09-10。实际读取：2026-09-29 20:07:28 CST。仅提取作者的 Atlas Tree Variants 正文，未把评论区意见并入作者策略。

点击核验：初始已选中；实际点击后确认名称与正文，建立 Expedition 基准。

识别本套正文的特征：3 个辐照碑牌；Grand Expedition 符文选择、Opulent 与终段 7+ 符文组合。

中文为归纳，英文专名用于核对。必需、可选、建议、不确定及未说明之处均按本方案分别保留；未另行检验当前游戏机制、行情或收益。

## 地图要求

- 场景为 Grand Expedition。作者认为 **8 词缀 Waystone** 的收益最好，优先较高的怪物效果（monster effect）；怪物稀有度也较好，物品稀有度可用，怪群规模（pack size）在此策略中评价较差。
- T16 也可用，但作者认为成本较高且已非必需：T15 在 Grand Expedition 中能达到区域等级 81，仍可掉落物品等级 82 的 exceptional bases。
- 以上是本页作者的配置与收益判断，不是本次独立实测结果。

## 碑牌种类与数量

- **3×Irradiated tablets（辐照碑牌）**。
- 主配法追求每张带“额外 2 条随机地图词缀”，并搭配怪物效果或稀有怪数量增加。

## 关键词缀

| 用途 | 作者条件 |
| --- | --- |
| 主配法重点 | 额外 2 条随机地图词缀 + 怪物效果／稀有怪数量 |
| 可接受次选 | 物品稀有度；作者认为弱于上述两种搭配属性 |
| 廉价碑牌 | 稀有怪数量、怪物效果、怪物稀有度，三选二 |
| 地图优先级 | 高怪物效果；怪物稀有度也好；物品稀有度尚可；pack size 评价差 |

## 大师选项

- **Jado**：Unexpected Missions、Eastern Knowledhe、Partial Translations、KJeen appraisal。
- 上述拼写按正文保留；其中 Eastern Knowledhe、KJeen appraisal 疑似有拼写问题，本记录未擅自改成其他选项。
- Doryani 也可行，但作者称自己使用 Jado 的结果更好；未列 Doryani 的具体选项。

## 实际刷法

1. 开局优先收集好符文，不必过分在意组合只有 4–6 个；接近结束时，多保留 **7+ 符文组合**。
2. **Opulent** 是作者最重视的符文，地图出现时通常优先前往。终段若已有含 Opulent 的 8–9 符文组合、又没有作者所称的 prolif 符文，也可以就此结束。
3. 符文不叠加，因此各取一种。作者分级为：SS＝Opulent；S＝Power、Death、Bond；A＝Time、Oath、rebirth（本名单中唯一蓝色符文）；B＝其他紫色符文；C＝其他蓝色符文。
4. 开局的 5 符文组合若没有好紫色符文，通常重投；B 档组合只有 3–5 个符文时可以重投；接近终段一般保留 7+。
5. 作者还要求在其所称的“全为 5、6 或 7 的地图”积极重投，理由是基础结果不会差；原文没有进一步定义这类地图，本记录保留这一适用条件。
6. 通常保留价值 **至少 3 Divine** 的好奖励。低于此数由地图情况决定；如果地图有很多差符文，作者也会保留 1–2 Divine 的奖励。

## 作者提供的减配办法

- 碑牌改为“稀有怪数量／怪物效果／怪物稀有度”三选二。作者明确说收益更低，但地图更容易、碑牌便宜很多，**用于非 Aldur Saga 地图**。
- 最便宜的地图准备方式：自制 **70% effect、6 词缀**的 Waystone，然后腐化；此处保留作者的 effect 表述。
- 可以使用 T15；作者没有要求为 T16 额外付出成本。
