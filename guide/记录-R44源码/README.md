# R44显示层维护

输入须为完整、未修改的R43目录。输出必须为新目录，拒绝覆盖或嵌套。

```sh
python build_r44.py /path/to/R43 /path/to/new/R44
```

生成依赖Python标准库；构建不改变输入。构建产生的build_paths.json指向输出目录。

复跑浏览器检查需Python Playwright、Chromium及Node。test44.py默认将同目录base作为原R43对照，可用本地目录软链接指向R43；浏览器可执行文件在脚本内按实际环境调整。依次运行`python test44.py 1`至`python test44.py 4`，不要把被限时终止的批次计为完成。脚本中的内存加载用于受限环境交互验收，不能替代真实部署／客户端测试。
