## 查看方法

1. `装备与珠宝核对.md`：每套一个总览块，逐件装备及逐颗珠宝。`装备面板全表.md`列出全部面板属性及有关源描述原值。

3. `异界方案核对.md`：按七套列出地图/碑牌/操作条件、大师已选、多选节点已选及大师候选效果。
4. `builds.json` / `atlas.json`：机器可读交接；每件/每颗/每个选择有状态、源关联和证据引用。英文 build 名称保持原样。
5. `evidence/`：必要浏览器原生截图、完整悬浮框原文/HTML、分支标签状态、公开数据摘录和采集日志。截图可受视口裁切；原文/HTML保留完整面板。人物 `Passive Tree-full.jpg` 与异界 `Atlas Tree-full.jpg` 为补存的全屏图。
6. `validation.json`：实际执行的19项数据核验。`manifest.json`：全部交付文件SHA-256（不包含清单自身）。`package-preflight.json`：打包前的JSON/链接/图片/敏感值检查。ZIP CRC与清单核验在打包程序创建文件后执行。
7. `scripts/`：本次实际方法、整理/打包代码与最小运行说明；采集已经执行，不需要用户截图、另存网页或导出HAR。

## 状态读法与数值原则

- `panel_observed` / `source_and_panel_verified`：实际面板已取得，或与保存字段核对相同。
- `not_printed` / `not_explicitly_set` / `source_not_configured`：实际观察未打印、没有明确设置、或保存配置为空，保留区别。
- `tool_not_retrieved` / `visible_canvas_only`：本工具未自动取得该字段或只取得图像证据，不能说成原网站无数据。
- `source_panel_conflict`：网页当前面板与其保存字段存在差异；双方并存。
- 所有括号范围原样保留。交易查询中的 `min` 仅用于页面物品关联，不当作作者掷值或硬性目标；导入的数值描述也不覆盖范围面板。
- UI树计数两列按原样保存，源节点记录数量不简单等同消耗点数；Live Gear的Main与武器组存在重叠ID。没有修复作者加点或负数计数。
