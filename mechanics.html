冰缓不等于冻结；为什么先冻再狙击

冰缓是减速，冻结是另一种状态。主输出先建立冻结；狙击的完美释放、直接命中与消耗冻结分别满足，才有期望的强化爆发。一次最高伤害不代表每发都一样。

冰霜射击 / 狙击 / 简体数据 ↗

没闪电伤害，Early为什么点感电？

冰冻印记被激活时，充能印记生成感电地面，不要求先用闪电击中。感电使敌人承受伤害提高，冰伤也受益。感电几率与感电强度不同；点几率不能替代充能印记。武器Ⅱ相关效果的跨组触发/快照时点未作国服实测，不填写固定最终感电值。

充能印记 / 简体数据 ↗

虹吸印记不是按全部冰伤偷取

虹吸印记Ⅱ的规则是按物理攻击击中伤害偷取。冰射不同部分转伤不同，不能把总冰伤乘8%当恢复。击杀回蓝只能在有击杀时兑现；无小怪首领必须另测药剂、消耗与印记持续。

虹吸印记Ⅱ / 简体数据 ↗

印记、增益、永恒印记是三件事

挂上印记不等于立刻激活。冰冻印记在冻结时激活，敌人印记和自身增益有各自计时。永恒印记只保护第一次激活不被消耗，不是永远不消耗。换目标重挂可能改变当前增益，依技能说明观察。

冰冻印记 / 永恒印记 / 简体数据 ↗

没有狂怒球，弹幕也不是无效

弹幕本身有基础额外重复；狂怒球增加重复。永续充能只影响消费，不负责产球；充能印记是感电地面，不是产狂怒球。重复攻击有伤害惩罚，不能把箭数乘以每次最大冰爆当实际伤害。

弹幕 / 简体数据 ↗

衣服上的荆棘能增加冰射伤害吗？

普通荆棘是另一种反击伤害，并非为每支箭附加物理点伤。这套弓玩法不围绕荆棘构筑；衣服先看生命、抗性、物品防御。衣服本身很好而顺带荆棘可以穿，不为荆棘专门换装。

荆棘 / 简体数据 ↗

命中、基础暴击、暴伤不要混算

攻击要命中才造成该次伤害。本地“暴击率＋3.1%”不是全局“提高3.1%暴击率”。只有暴伤却没有合理命中和基础暴击，收益有限；完美狙击不自动等于必定暴击。

暴击 / 简体数据 ↗

元素军械Ⅱ→Ⅲ不一定适用

Ⅲ与元素集中会改变被辅助技能造成元素异常的能力。主冰射承担冻结时不能随意装入；寒冰之捷上有元素集中，不代表要给冰射也装。辅助等级与未切割宝石等阶也要区分。

元素军械Ⅲ / 简体数据 ↗

为什么表里出现三个冰霜射击？

一个是手动主技能，另外两个可以分别镶在幻影射手和蜃影神射中。内槽冰射是主动宝石，不是辅助；全部算入属性需求。官方构筑格式对元技能支持有限，导入后还要手工核对内槽。

官方构筑格式 / 简体数据 ↗

有护盾不等于混合防御已完成

高物品护盾头、诡计面纱、闪避、偏转、恢复及生命抗性一起工作。头盔物品护盾≠角色总护盾；幽灵舞步不要套用旧版瞬回描述。受击后聚风/风舞者状态不同，满层城里面板不等于永远承伤能力。

幽灵舞步 / 简体数据 ↗

穿透、减抗、反转不是全都可直接相加

普通抗性穿透默认有0的边界，特定特殊效果另论。拉其塔之流按反转的敌人抗性结算；先减正抗再反转可能降低这部分收益。04未带这颗辅助，不把05的计算套过来。

抗性穿透 / 简体数据 ↗

05的风舞者为什么要单看生命保留？

05连接阿兹里的圣礼，改变为生命保留。不能把它仍按普通30精魂加入总和；要看装好整组辅助后的生命保留比例与剩余生命。网站把精魂与生命分开录入，不自动声称特殊连接资源已算对。

网站以你提供的0.5.5六份快照为原件。外部数据库为读取时的国际服数据，简体译名不等于腾讯客户端逐条验证。旧0.3/0.4的冻结、狙击、护盾和辅助规则不能直接沿用。
