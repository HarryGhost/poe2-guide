# 网站源码与重建

网站运行不需要Python、Node、服务器、网络或登录。浏览器打开根目录 `index.html` 即可。

## 修改与重建

使用 **Python 3.9 以上**即可（标准库，无第三方依赖；本仓库在 3.9.6 上验证过重建逐字节一致）：

```text
python 源码/build.py
```

生成器从根目录 `data` 读取阶段、原件与术语，覆盖根目录22个HTML和 `assets`。
`content.py` 是中文编辑说明；`style.css`、`app.js`、`compare.js` 分别为样式、交互和对比。
切勿把原始 `.build` 的节点顺序当成加点顺序，切勿为了修数据冲突直接改原件。

## 全站一致性

所有页面由同一 `shell()` 与阶段模板生成。不要只改 `index.html`，否则重建会覆盖。
`index.html` 是L03（第二章未转冰射）的副本，12个阶段均有独立HTML。
各阶段数据保留在 `data/全站阶段与核算.json`；原始数据单独保存且不应覆盖。

## 依赖与部署

无CDN、远程脚本、远程字体、跟踪或账号依赖。更新时上传整套目录并保留相对路径。
外部作者/数据库链接需要网络；离线阅读、阶段切换及本地表格不需要网络。

浏览器存储、自动剪贴板可能被策略限制，程序有回退：可继续阅读，复制弹出文本手动Ctrl+C。
当前交付的浏览器检查为内存载入原始HTML与相同本地CSS/JS，真实file/HTTP导航在测试环境受策略限制。
因此应在正式部署环境补一次真实打开、持久化、下载和剪贴板权限检查。
