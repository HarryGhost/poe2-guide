# R6生成说明

使用Python 3.12或更高版本（原生成器使用新版f-string语法）。无需网络或第三方依赖。

```sh
python 源码/build.py
```

`data/Fubgun_异界后期打造.json`保存8条路线、原文、逐段译文、42条操作分解、30项材料和来源。
`源码/crafting.py`生成紧凑打造页与全部展开页，以及中文Markdown。
`源码/crafting.js`负责工艺选择、材料搜索与打印展开，不读取服务器进度，不修改任何原始构筑。
`源码/style.css`末段仅新增打造界面样式，继续使用C方案。

重建依据随包数据，不会联网更新游戏版本；原始作者数据与旧构筑保持不变。
源文件没有写的独立工艺不能擅自补成Fubgun的方法；未验证步骤须保留明确状态。

测试记录在“检查与预览”；历史R5测试单独隔离。本环境无法实际打开file://或localhost，浏览器测试采用内联同一份本地CSS/JS的内存HTML，不代替真实部署和游戏验证。
