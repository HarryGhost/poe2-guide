# 锐眼冰射 · Fubgun 版 · 0.5.5 国服

一个纯静态攻略站（单文件 `index.html` + 几个下载文件），部署在 GitHub Pages：
**https://HarryGhost.github.io/poe2-guide/**

来源：Mobalytics 上 Fubgun 的 [0.5.5 Ice Shot Deadeye](https://mobalytics.gg/poe-2/builds/ice-shot-deadeye)（英文），本仓库是中文整理版，
并把技能 / 辅助 / 升华 / 天赋大点 / 装备的名字换成了国服中文名。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 攻略本体（单文件，无外部依赖，无构建步骤） |
| `POE2-Fubgun-Ice-Shot-Deadeye.build` | **主下载文件**：93 点天赋（已排加点顺序）+ 11 组技能（含武器组、辅助宝石） |
| `锐眼冰射-Fubgun版.build` | 上面那份的副本（中文文件名） |
| `术语对照.md` | 中英文术语对照（技能 / 辅助 / 升华 / 天赋大点 / 装备 / 打造通货） |
| `外网资料/` | Fubgun 英文原文存档、国服实况角色配置快照、外网攻略汇总 |
| `归档-lowK版/` | 旧版（另一位国服作者 lowK 的版本）存档，含天赋树查看器 `tree-viewer.html` |

## 页面结构

总览 / 路线 / 装备 / 技能 / 天赋 / 打造 / **独狼** / **实战** / **陷阱** / 下载 / 问答，共 11 个 hash 路由。

其中「独狼」「实战」「陷阱」三页是按另一份逐条核对稿（GPT 整理，见 `外网资料/GPT整理-*`）的框架重排的：
独狼页 = 总优先级 / 每件装备的最低可用与替代 / 打造停手规则 / 暗金是否必需 / 里程碑；
实战页 = 输出循环 / 伤害底座 / 能量球真相 / 单体供蓝 / 防御细节 / 排障表；
陷阱页 = 版本边界 / 五个"看起来该做其实别做" / 仍无法确认的项目清单。
`index.html` 由 `/tmp/site/gen2.py` 生成（本机脚本，不在仓库里）；直接手改 `index.html` 也可以，
但下次重新生成会覆盖。

## 数据来源与边界

按来源分三类，别混着当一个人写的：

1. **Fubgun 原文（有出处、逐句翻译）**：技能组与辅助宝石、武器组规则、首领连招、六连/品质优先级、
   元素军械 II、升华顺序、装备 6 阶段与各部位词条、打造配方（弓/箭袋/项链/头盔/绿宝石）、
   抗性/精魂/稀有度、1–30 级练级技能与换装节点（11 级守望者弓 / 16 级反曲弓 / 24 级小换技能 / 31 级换冰）、
   首领顺序、药剂档位、飞羽流矢、蓝耗三个来源、头盔涂油 Zarokh's Gift、精魂 145–147。
   来源：`外网资料/冰射锐眼-英文原文-Fubgun.txt` 与 `外网资料/冰射锐眼-练级篇原文.txt`。
2. **国服实况角色数据（不是 Fubgun 的）**：`.build` 里的 93 个天赋节点，其中 **87 个**取自一位国服锐眼玩家
   （92 级 · 异界 T16）的公开角色数据，另 6 个是为连通游侠起点补的。Fubgun 的树只有图片、拿不到节点 ID，
   所以这块是替代方案。同样来源的还有「国服实况参考」面板块。
3. **本仓库整理**：中文化、排版、术语表、加点顺序标注（按「离起点越近越先点」）。

其他核对情况：

- 技能、辅助、传奇中文名：`poe2db.tw/cn` 逐条核对。
- 天赋大点中文名：国服 WeGame 天赋模拟器节点数据 + `poe2db.tw/cn` 双向核对。
- 打造通货中文名：已全部核对（左旋/右旋死灵预兆、遗存颚骨、深渊回响预兆、破溃宝珠等），
  仅 `Vaal Infuser` 未查到官方页，保留英文并标 ⚠。
- 作者页面上写的 `Primal Armament` / `Martial Tempo` 在 0.5.5 辅助宝石池里**不存在**
  （全量 554 条比对过），按上下文映射为 元素军械 II / 快速攻击，另 `Persistence` → 持续时间延长 II。
