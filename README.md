# 六分支进阶网站 v2.0

入口是 `index.html`。完整解压后用浏览器打开；也可发布整个目录到静态站点。

## 内容与数据源

01→02→03→04→05按条件进阶；06是有升华字段冲突的独立实装快照。
默认当前BD为01，长期目标独立。技能、装备、天赋、操作、资源录入和下载共享唯一当前状态。

`六分支完整资料.html` 为无JavaScript全量资料；`数据`目录含完整映射和30组方向比较。
`Build-Fubgun`中的原件不改动；06仅为`.build.txt`只读资料。

## 源码与重建

使用Python 3.9及以上（生成脚本只依赖标准库；本次实际执行环境为Python 3.13）。在网站目录执行：

```sh
python _source/build.py
```

生成器读取 `_source/data.json`、`content.html`、`style.css`、`app.js`，生成两个HTML和公开数据副本。原始构筑字节或节点行序不匹配时停止构建。

本地预览也可以在本机执行：

```sh
python -m http.server 8000
```

在浏览器打开终端提示的本地地址。此步骤是使用说明，不是声称本包已经公网部署。

发布时应同时保留所有资源目录；无需Node依赖、CDN、外部字体或账号。正文引用外部来源只在点击时打开。

## 维护原则

修改叙述不要修改原始快照。更换作者版本时需要重新核对各分支、映射、差异、哈希和原文件，不能把不同版本拼接。
`data.json` 中的 `raw` 是原件；`profile` 是按原件及来源整理的阶段建议；节点的 `status` 决定名称可信度展示。
只查看一种来源状态不会删除其他记录，无脚本资料始终保留全部记录。

## 自动检查

包上一级的 `检查与说明/运行检查.py` 是可选验收脚本。需要 Python、beautifulsoup4、Playwright及Chromium；可用 `CHROMIUM_PATH` 指定浏览器路径。
脚本不操作游戏、不发送外部请求；用Chromium内存渲染实际HTML，另用Python本地HTTP核对资源字节。
真实国服运行、客户端译名和完整合法加点路径尚未验收。
