# R42维护源码

阅读网站不需要构建。维护生成需要Python3、Node、Acorn（在此目录运行 `npm install acorn`，或配置ACORN_PATH）。

```sh
python build42.py "/绝对路径/R41原站" "/绝对路径/全新R42输出"
```

输入必须是发布信息为R41的完整包；输出必须不存在，且不能与输入相互包含。脚本不会覆写已有目录。脚本生成814份构建输出；最终发布的维护副本、说明、检查与SHA清单是构建后的发布收尾，不冒充重复构建输出。

网页运行不依赖Python、Node、Acorn或npm。对照维护应保留原BD、技能、天赋、Atlas、四原版过滤器与原档案字节；所有新增解释从guide42、references42及当前渲染代码维护。不要把当前R42当作R41输入反复叠加。

测试脚本在相邻R42检查目录，复跑需要Playwright和Chromium；路径常量与浏览器位置需按环境调整。工具调用/渲染检查不是游戏内加工，也不是用户域名部署。
