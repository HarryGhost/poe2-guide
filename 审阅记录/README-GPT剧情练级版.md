# 锐眼冰射：剧情练级与紧凑界面 v3.0

入口为`index.html`；需完整解压。支持直接打开或部署整个目录为静态站点，不使用外部脚本、CDN、账号、分析追踪或字体文件。

## 阅读和状态

默认进入剧情练级。六个剧情阶段为1–14、15–23、24–30、31–41、42–59和60+通关衔接。前五段技能按作者分支核对；最后一段明确是编辑的沿用方案，不冒充作者60+原始配置。
当前剧情阶段、当前异界BD和长期目标独立。人物达到60级不自动认定通关，也不自动切换天赋。异界01→05按装备和资源条件进阶，06冲突原件只读。

技能默认紧凑列表：所有辅助可见，英文、ID和机制展开。支持整段复制、搜索、紧凑/舒适间距、手机布局、深浅色。偏好保存使用新的v3键；旧版浏览器勾选不自动迁移。浏览器禁用本地存储时仍可读，但不能保证刷新保留。

## 无脚本与数据

- `剧情练级速查.html`：所有本地剧情段技能、装备建议、操作和奖励，不依赖JS。
- `六分支完整资料.html`：全部原有异界装备、技能和天赋记录。
- `数据/剧情练级结构数据.json`：剧情技能以本地键关联中文/英文词典，不是假造的游戏Metadata ID。
- `数据/六分支原始及中文映射.json`：完整网站数据，包括剧情、异界、词典与来源。
- `Build-Fubgun`：原始异界文件字节不变；06为`.build.txt`。

## 构建

Python 3.9以上，生成脚本仅用标准库。运行：

```sh
python _source/build.py
```

读取`data.json`、`content.html`、`style.css`、`app.js`、`leveling.js`与`leveling_static.py`，生成三个HTML、JSON数据副本。`leveling.js`注入原脚本IIFE内，不是另加网络请求。
原始构筑哈希/JSON或节点顺序不匹配时停止构建。不要绕过检查来拼接作者其他版本。

可选本机预览：

```sh
python -m http.server 8000
```

在本机浏览器打开终端提示的地址。此为使用方法，不代表已部署。

## 测试

上一级`检查与说明/运行检查.py`需要Playwright、beautifulsoup4及Chromium。可用环境变量`CHROMIUM_PATH`指定浏览器路径。
本次测试使用Chromium对实际HTML进行`set_content`内存渲染，覆盖多宽度、分支、技能完整性、切换、复制降级、资源预算、深链接等；本地存储的序列化往返使用明示的内存测试夹具。运行环境阻止`file://`导航，因此没有把测试结果写成真实本地文件导航、线上部署或游戏导入通过。

## 内容边界

本地练级天赋没有完整坐标/连线/合法点序；提供作者对应阶段入口及升华说明。60+原版分支未成功读取，本地为42–59延续直到剧情完成。全量腾讯客户端名称、实际计点与导入、资源持续性及首领能力仍需游戏验证。装备取舍和操作建议与作者配置分别标记，不因未知而编造。
