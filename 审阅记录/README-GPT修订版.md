# 锐眼冰射＋狙击：新手友好修订站

**本目录就是可运行的静态网站。主线为上传快照的04 Crit Hybrid；不是新造的毕业实测。**

## 打开与部署

先完整解压，再双击 `index.html`。页面文字、搜索、分支筛选与精魂算术工具均不需要网络。下载 `.build`、CSV 等需要保留同级子目录，不能只复制HTML后期待下载链接仍可用。

交给DSH更新时，将本“网站”目录的内容同步到原仓库的站点根目录。保留 `.nojekyll`、`Build-Fubgun/`、`天赋节点清单/`、`数据/`。这是可部署文件；本次没有执行远程上传或线上发布。

## 阅读顺序

首页选择实际阶段 → 看三项当前任务 → 根据需要打开技能、装备、实战排障。默认技能/装备/天赋均为04号。更换查阅分支不会把它变成已经适合你角色的方案，也不改变首页实际阶段。

01–03：过渡参考；04：保留狙击的定型参考；05：已无狙击的最高配对照；06：文件头与升华节点冲突，只能下载 `.build.txt` 隔离文本，不应直接导入。

## 文件与修改

- `index.html`：生成后的单文件页面，无CDN、无外部脚本。
- `_source/content.html`：攻略正文。
- `_source/app.js`：阶段行动、动态技能/装备/天赋、交互、搜索与排障内容。
- `_source/style.css`：响应式与深浅色样式。
- `_source/data.json`：六份原件与对应中文名、来源和统计；未改变原始节点/连接。
- `_source/build.py`：相对路径生成器，Python 3.9+，仅标准库。
- `Build-Fubgun/`：源文件原字节备份；06采用隔离扩展名。
- `天赋节点清单/`：分开公共、武器Ⅰ、武器Ⅱ、升华，保留原行号及名称状态。
- `数据/`：完整JSON、CSV。

重新生成：

```sh
python3 _source/build.py
```

不要只改 `index.html` 又在之后运行生成器覆盖。攻略文本改 `content.html` 或 `app.js`，数据改动必须先有证据并更新核验。

## 数据边界

六份原件共有91条装备记录、60组主技能、238条内嵌技能/辅助记录、969条天赋记录（含重复与各武器组，**不是969个天赋点**）。54种不同技能/辅助与29种装备名称有字典；DSH对265种天赋提供了中文映射，其中只有标为“简体资料有来源”的部分附有ID对应来源，其余仍待复核。

`.build`在技能/装备记录中可有 `level_interval`，但本批天赋记录没有逐节点等级区间。不能把“所有导出都没有level_interval”当事实，也不能把数组行序当合法点序。

原件没有完整被动坐标和连线、合法逐级加点顺序、实际国服点数与导入测试、珠宝实装/种子、全技能等级/品质与精确资源预算、同配置的国服全部终局实证。本网站保留这些边界，不靠“修订完成”把它们变成已验证。

## 隐私与离线

本地存储键：`poe2-guide-reviewed-v1`。只保存阶段、独狼/交易选择、主题和个人勾选；不上传，不同步，不读取游戏。禁用本地存储不会阻止阅读。精魂工具是输入后的算术汇总，不是游戏机制模拟器。

## 维护验收

修改后检查所有章节、返回首页、浏览器前进后退、折叠深链接、搜索、复制连接、分支切换、下载路径、320/390像素窄屏和本地存储禁用场景。不要把网页运行测试说成游戏实战或国服名称全量验证。
